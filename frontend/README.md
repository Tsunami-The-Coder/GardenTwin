## Your starting steps

1. Sketch the main flow: configure a garden → run a season → scrub the timeline → compare strategies.
2. Start with the agreed pilot: tomatoes, Edison, New Jersey.
3. Sketch these screen areas:
   - Garden settings: location, plant, planting date, soil, watering and fertilizer settings.
   - Garden preview: selected day, growth stage and environmental conditions.
   - Draggable season timeline.
   - Graphs for soil moisture, temperature, nutrients and plant health as the backend supports them.
   - Strategy comparison: water use, stress and estimated productivity as the backend supports them.
4. Design empty, loading, error and results states.
5. Label historical weather, simulated outcomes and AI recommendations clearly.
6. Ask Ayaan which outputs will be available for the first version. Agree on names, units and missing values in `shared/API_PLAN.md`.
7. Create a sample response with Ayaan before wiring up the frontend. Label any sample values as illustrative.
