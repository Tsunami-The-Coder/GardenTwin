# Team starting checklist

## Together: first 20–30 minutes

- [ ] Confirm both teammates can access and clone the repo.
- [ ] Confirm the pilot and one user decision the first demo will support.
- [ ] Agree on the smallest feature set you can finish.
- [ ] Mark fertilizer, nutrients and yield as first-version features or later work.
- [ ] Agree on units and initial request/response fields in `shared/API_PLAN.md`.
- [ ] Pick an integration checkpoint and who will submit.

## You: UI/UX

- [ ] Create `ui-ux/initial-design`.
- [ ] Sketch configuration, timeline and strategy-comparison views.
- [ ] Design loading, missing-data and error states.
- [ ] Agree with Ayaan on available outputs before connecting the UI.

## Ayaan: backend + local AI

- [ ] Create `backend/initial-setup`.
- [ ] Set up his Windows environment and choose dependencies.
- [ ] Confirm weather/soil coverage and document sources.
- [ ] Define the simulation, AI task and evaluation plan.
- [ ] Provide the actual local run commands and agreed example response.

## Together: integration and handoff

- [ ] Test one garden configuration from input through results.
- [ ] Check that both strategies use the same historical weather.
- [ ] Label sample, historical, predicted and simulated results accurately.
- [ ] Record actual results and at least one failure.
- [ ] Complete credits, write-up and submission checklist.
