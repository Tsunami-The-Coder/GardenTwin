# Local model workspace

Owner: Ayaan.

Use this folder for local model artifacts after choosing and implementing the approach. Large weight files are ignored by default.

Record when ready:

- Model/library and exact version.
- What is predicted and in which units.
- Training data and preprocessing.
- Training, validation and test date ranges.
- Simple baseline and actual evaluation results.
- Windows setup and inference commands.
- Hardware requirements and whether the GPU is used.
- Known failures and limitations.
- How your teammate and judges can reproduce the run or obtain the weights.

No model or training code is included in the setup.
