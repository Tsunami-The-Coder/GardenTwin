# Data workspace

Owner: Ayaan.

Pilot location: Edison, New Jersey. Confirm the pilot garden or public location before selecting a weather grid cell and soil map unit.

Potential public sources to investigate:

- [Open-Meteo historical weather](https://open-meteo.com/en/docs/historical-weather-api): historical weather and derived variables. Record whether values are reanalysis estimates or observations.
- [USDA NRCS Web Soil Survey](https://websoilsurvey.nrcs.usda.gov/app/): investigate local soil mapping and available soil properties. A city name alone does not establish one uniform soil type.
- [FAO crop-water guidance](https://www.fao.org/4/x0490e/x0490e00.htm): a reference to assess when designing and documenting the simulation.

These are research starting points. No data has been downloaded, no site-specific soil values have been selected, and no source is integrated yet.
